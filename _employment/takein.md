## Responsibilities
- Reviewed the cloud backend, mobile app, firmware, hardware testing and data tooling against the company's wider strategy
- Acted as the founders' sounding board for technical and product decisions
- Translated technical progress and test updates into what they meant for timing and readiness
- Created system and data-flow diagrams, a glossary and walkthroughs for the founders

## Key contributions
- Delivered a 46-page project review with clear, realistic next steps
- Ran workshops to turn the founders’ vision into a written North Star, defining each part of the app’s purpose, content and design where decisions were settled
- Turned the North Star, brand colours and the founders’ style references into clickable app screens, with mock data and toggles to compare features, so design and build worked from the same picture.
- Designed how breath data is captured, stored, aggregated and shown to users, balancing scientific accuracy, scalability and user value
- Set out the timing and skills behind each next step, so the founders could plan with confidence
